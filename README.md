# Manual de piezas · Arcor en Casa

Página para diseñadores: elegís qué estás armando (Home, Home event, Recetas, Micrositio o Ficha de producto) y ves las piezas a entregar, separadas por desktop y mobile, con medida, formato, peso máximo y dónde va cada una en el sitio.

Abrí `index.html` en el navegador. No necesita build: es HTML estático con las capturas en `img/`.

Detalle visual completo en el board de especificaciones técnicas en Figma.
